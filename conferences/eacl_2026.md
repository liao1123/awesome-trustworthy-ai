## 筛选说明

- 官方论文总数：445；ACL Anthology 的正式主会卷复算为 Long Papers 394 篇、Short Papers 51 篇。
- 初筛候选：125；先完整扫描 445 个标题，再结合摘要中的安全语义补查标题未显式出现 `safety`、`attack`、`privacy`、`hallucination` 或 `misinformation` 的候选。
- 最终收录：75。
- 收录口径：逐篇阅读 Anthology 摘要，只保留把模型越狱与护栏、危险能力、训练数据泄漏与遗忘、生成内容溯源、评测操纵、内容安全或具备明确高后果的事实性失效作为核心问题的工作；每篇只进入最匹配的一个分表。
- 边界案例：一般语言能力与常规鲁棒性、只改善普通 agent 任务完成率、常规差分隐私、一般公平性，以及仅以医疗或法律背景包装的准确率研究不收录；普通 hallucination 或 uncertainty 论文只有在明确研究安全检测、高风险决策、科学证据或社会危害时才保留。
- 范围边界：Findings 与主会录用在官网和 Anthology 中分列，故不混入本页；`SafeSearch: Improving the Safety of Web Search Agents via Bias-Aware Guardrails` 等 Findings 论文不计入 445 篇分母或下列论文表。
- 链接规则：`Official` 统一指向 ACL Anthology 正式论文页；只有作者或论文可直接回证的代码入口才记录为 `Code`，论文仅声称公开但未给出可核验 URL 时不猜测仓库。
