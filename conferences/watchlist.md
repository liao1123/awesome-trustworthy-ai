# 会议追踪清单

这里定义需要关注 accepted-paper 列表的会议范围。具体年份的官方列表 URL 在采集时写入 collection manifest。

| 类别 | 会议 |
| --- | --- |
| 通用机器学习 | NeurIPS、ICML、ICLR |
| AI 与多智能体 | AAAI、IJCAI、AAMAS |
| 负责任 AI | FAccT、AIES、SaTML |
| 安全与隐私 | IEEE S&P、USENIX Security、ACM CCS、NDSS、PETS |
| 自然语言处理 | ACL、EMNLP、NAACL |
| 计算机视觉 | CVPR、ICCV、ECCV |
| 人机交互 | CHI、CSCW |
| 机器人与自主系统 | CoRL、RSS |

是否收录取决于论文内容，而不是会议名称。专题 workshop 可以作为发现入口，但必须明确标注其 venue 层级，不能与主会录用混写。
