# 单篇论文精读 Prompt

## 参数

- 论文 ID：`{{PAPER_ID}}`
- 精读重点：`{{FOCUS|方法、实验、安全含义、局限与复现}}`

## 任务

读取主注册表中的论文记录和可访问全文，使用 `templates/paper-note.md` 创建或更新详细笔记。

1. 阅读正文而不只依赖摘要；无法访问全文时停止并明确说明，不伪造精读结论。
2. 识别研究问题、威胁模型、关键假设、方法、baseline、数据、指标和主要结果。
3. 将作者主张、实验直接支持的结论和自己的推断分开写。
4. 检查外部有效性、数据污染、评测泄漏、统计不确定性、缺失 baseline 和双重用途风险。
5. 建立与仓库已有论文的关系，给出可执行的复现或后续阅读计划。
6. 保存到 `papers/<year>/<paper-id>.md`，更新 registry 的 `note_path` 与 `review_status`，再运行全部检查。
