# 单领域补全 Prompt

## 参数

- 领域 ID：`{{DOMAIN_ID}}`
- 时间范围：`{{YEAR_FROM|不限}}` 至 `{{YEAR_TO|今天}}`
- 目标数量：`{{TARGET_COUNT|50}}`
- 重点：`{{FOCUS|基础、经典、代表方法、benchmark、近期进展}}`

## 任务

对指定领域做一次有边界的系统补全，而不是只搜索最近论文。

1. 读取 taxonomy 中该领域的定义、子主题、关键词与现有领域页。
2. 先建立问题分解，再分别检索综述、奠基工作、主要方法、反例/批评、benchmark 和近两年进展。
3. 使用一手论文页核对元数据，通过引用链和正式综述发现遗漏，但不依据引用数自动判断质量。
4. 将候选分为 `foundation`、`core`、`advanced`，并标注 `essential`、`recommended` 或 `reference`。
5. 检查子主题覆盖是否失衡；宁可明确留下 coverage gap，也不要用弱相关论文凑数。
6. 写入前按仓库规则去重，随后重新生成领域页并运行全部检查。

## 完成报告

给出新增论文、合并记录、子主题覆盖变化、仍缺失的关键问题，以及建议优先精读的五篇论文。
