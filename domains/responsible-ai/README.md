# Responsible AI

[返回领域目录](../README.md)

本目录整理公平性、与安全问题直接相关的可解释性，以及人机监督等社会技术问题。论文必须明确评测对象、受影响群体、安全 threat model 或人机决策结果，避免只以抽象“责任”标签代替可检验的风险定义。一般可解释性与模型透明度研究不纳入；直接服务于安全对齐、攻击诊断、欺骗监控、隐私、内容安全、Agent 故障或安全关键决策的解释方法可以收录。

## 子领域

| 方向 | 页面 | 范围 |

| 公平性 | [公平性与 Bias](fairness-and-bias.md) | 有明确受影响群体、危害路径和审计指标的 demographic bias、worst-group evaluation、reward bias 与 mitigation。 |
| 安全可解释性 | [安全可解释性与 Transparency](explainability-and-transparency.md) | 与具体安全 threat model 绑定的 attribution、mechanistic interpretation、faithfulness 与 auditability。 |
| 人机系统 | [Human-AI Interaction 与 Oversight](human-ai-interaction-and-oversight.md) | 监督失效、危险依赖、风险沟通与高风险决策结果；排除一般体验和抽象设计倡议。 |
