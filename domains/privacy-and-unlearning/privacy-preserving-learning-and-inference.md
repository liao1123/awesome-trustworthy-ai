# 隐私保护学习与推理

[返回上级目录](README.md)

## 研究方向

研究在训练、适配、协作和推理阶段限制数据暴露的方法，覆盖 differential privacy、federated learning、secure computation、TEE、数据最小化与 contextual privacy policy，并同时考察 utility、系统成本和可验证保证。

## 研究脉络

- **训练期保护：** Differential privacy 和 federated learning 将保护边界从集中训练扩展到多客户端更新与个体记录。
- **推理期保护：** split inference、secure computation、TEE 与输入变换尝试同时隐藏 prompt、特征和模型参数。
- **语境化策略：** 隐私不再只由固定 PII 列表决定，研究开始建模用户意图、上下文边界和 Agent memory 的最小披露。
- **当前边界：** 形式保证、端到端系统实现和隐私—效用—延迟三者仍经常被分开评测。
