# 模型微调安全

## 领域说明

模型微调安全研究模型在监督微调、偏好优化、强化学习、参数高效微调和知识蒸馏等后训练过程中产生、放大或传递的安全风险。该领域既关注恶意数据和自适应攻击，也关注看似良性的任务数据引发的安全退化、跨任务错位、隐蔽行为迁移，以及模型能力被未授权复制。数据检测、筛选、重加权和调度作为有害微调的防御方法收录，不再单设子领域。

本文件是模型微调安全领域的目录页，不直接存放论文。论文应进入下面最匹配的子领域。

## 子领域目录

| 子领域 | 主要研究问题 |
| --- | --- |
| [有害微调攻防与安全退化](harmful-fine-tuning.md) | 分析恶意或良性后训练如何破坏既有安全对齐，并设计数据、参数、表示、路由和训练过程层面的攻击与防御 |
| [涌现错位](emergent-misalignment.md) | 研究狭窄任务微调为何会泛化为跨领域错位，以及如何监测、解释和抑制这种泛化 |
| [潜意识学习](subliminal-learning.md) | 研究语义无关或看似无害的数据如何隐蔽传递偏好、人格、偏见和不安全行为 |
| [反蒸馏](anti-distillation.md) | 阻止或检测第三方通过模型输出、推理轨迹或受保护数据复制能力，并以主动诱捕、水印和指纹支持防护与归属验证 |

跨越多个问题且对各方向都有独立贡献的论文，可以在相应子领域交叉收录。

## 分类规则

1. 以恶意微调、良性微调造成的整体安全退化，或数据、参数、表示、路由和训练过程防御为核心的论文进入“有害微调攻防与安全退化”；样本或 token 的检测、过滤、选择、重加权和调度归入其中的“数据级防御”。
2. 狭窄或局部行为训练泛化为广泛错位，且重点在其成因、表征、监测或干预时，进入“涌现错位”。
3. 隐藏特征通过语义无关、经过过滤或看似良性的载体数据从教师传给学生时，进入“潜意识学习”。
4. 以阻止或检测未授权能力复制、推理轨迹蒸馏、受保护数据学习，或验证蒸馏归属为核心时，进入“反蒸馏”。
5. 一篇论文有多个独立贡献时可以进入多个子领域，但每个子领域内只能出现一次。
6. 新建其他微调安全子领域时，直接创建 `<subdomain>.md`，并在本目录补充入口和范围。
