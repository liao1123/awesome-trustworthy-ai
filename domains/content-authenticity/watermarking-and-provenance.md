# 生成内容水印与 Provenance

[返回上级目录](README.md)

## 研究方向

研究在文本、代码、图像、视频、音频与 3D 内容中嵌入或验证来源信号，覆盖 zero-bit/multi-bit watermark、公开验证、语义绑定、局部定位、移除与伪造攻击。

## 研究脉络

- **可检测标记：** Watermark 从 token partition 和生成扰动建立低成本机器内容标记。
- **容量与鲁棒性：** Multi-bit、semantic 与 latent watermark 同时优化消息容量、质量和 paraphrase/transform robustness。
- **攻防评测：** Removal、forgery、bias inversion 和 adaptive RL attack 揭示平均扰动测试无法代表最坏情况。
- **可验证来源：** Public verification、mixed-source localization 与 provenance protocol 尝试把检测证据接入内容流转。
